# Workflow Éditorial

Ce dossier contient les articles organisés selon leur statut dans le workflow éditorial.

## Structure

### `drafts/`
Articles générés automatiquement en attente de révision humaine. Ces articles doivent être examinés, validés et éventuellement modifiés avant publication.

### `published/`
Articles validés et prêts pour la publication. Ces articles ont été révisés et approuvés pour être affichés sur le site.

## Workflow

1. Les articles générés automatiquement sont placés dans `drafts/`
2. Un éditeur humain révisionne et valide les articles
3. Une fois validés, les articles sont déplacés vers `published/`
4. Les articles publiés sont ensuite utilisés par l'application frontend
